  assets/*.webp (material visual)

PUBLICAR EN GITHUB PAGES
1. Crea o abre tu repositorio en GitHub.
2. Sube index.html y la carpeta assets COMPLETA, manteniendo nombres y rutas.
3. En Settings > Pages, selecciona Deploy from a branch > main > /(root).
4. Abre la URL publicada; pulsa ENTRAR AL DESAFÍO para iniciar la canción.
5. Ajusta Música y Efectos por separado en CONFIG. Volumen inicial de la música: 88%.

IMPORTANTE
- El navegador requiere un toque/clic antes de reproducir música.
- La pista musical completa ocupa aprox. 48 MB en 4 secciones, cada una menor a 25 MB para subir desde GitHub web.
- Se reproducen en orden y se repiten al finalizar; solo se descarga la sección necesaria.
- El archivo HTML abierto sin la carpeta assets NO podrá reproducir el MP3.
- Antes de publicar fotos o música comprueba que tienes permiso para distribuirlas públicamente.
- La bandeja de mensajes se sitúa FUERA de la cancha para evitar tapar al personaje.
- Los castigos incluyen movimiento real de Peky (salto, sentadilla, abdominal, pingüino y baile).
